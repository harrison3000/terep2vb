The text

Four sections. header: drive (rear, front, all), the unknown word at 0x06, and the game's state bytes when they are not zero. vertices: vertex[i] = (x, y, z) radius r body | reference | wheel front | wheel back [velocity (x, y, z)], in tiles (a map cell: the OpenGL renderer's scale), as decimals; the reference vertex is where the in-car camera sits. springs: spring vertex[a] - vertex[b]: type t shift s rest r last l min m max n (type 0: a rope between min and max; 1: a spring that bends or breaks; more: a damper). program: how the car is drawn, one instruction a line:

pixel P color c                    nearer P, P          facing P, P, P
flat color 0x0c0c: P, P, ..., P     (the last point closes the polygon; 0xf0f0 and up: glass)
shaded: P shade, P shade, ...       shaded_tab base b: P index, ...
textured: P (u, v), P (u, v), ...   (texels of the car's .pcx)
sprite P size s: (u, v) (u, v) (u, v) (u, v)
wheel P, P   and nine lines   view w0 w1: (u, v) (u, v) (u, v) (u, v)
sort2 La, Lb     goto L     gosub L     if visible goto L     if hidden goto L
nop     end     data 0x.., 0x..     L123:   (a label)

Points: vertex[i], shadow[i] (its shadow on the ground), axle[0], axle[1] (the front axle, steered), point[k]. "visible" and "hidden" are the result of the last facing or nearer test. Everything after a # is a comment.
